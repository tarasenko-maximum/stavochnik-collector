# Stavochnik Collector

Круглосуточный сбор котировок для проекта «Ставочник» (арбитраж букмекер ↔ биржа): только код
клиентов источников и движка вилок, без бизнес-документов и исследований — те остаются в приватном
репозитории.

Репозиторий публичный сознательно: у публичных репозиториев минуты GitHub Actions не тарифицируются,
а у приватных — 2000 минут в месяц (около часа в сутки). Это единственная причина публичности; ключи
API хранятся в GitHub Secrets и в коде не фигурируют.

Зачем именно раннер GitHub, а не собственный сервер: букмекер Pinnacle и биржа Smarkets блокируют
запросы с диапазонов адресов известных хостинг-провайдеров (проверено на Hetzner — 403), но не
блокируют раннеры GitHub Actions (Azure) — это единственная площадка, где виден полный контур из
четырёх источников одновременно.

Как это устроено: `.github/workflows/collector.yml` запускается по расписанию, скачивает накопленную
базу с основного сервера проекта, дособирает данные в окне ~5.5 часов, отправляет обновлённую базу
обратно. Результат виден на общем дашборде проекта.
